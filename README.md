# 玻璃车库 · GLASS GARAGE

七辆超跑模型的互动收藏柜。桌面同时陈列七辆，手机可左右滑动或通过七车型标签选择。点击玻璃车盒抽出模型，探索车门、舱盖、灯光、展示换色和各车型专属玩法。

每辆车均提供独立发动机外观、部件热点、完整气缸运转和教学拆装台。发动机默认暂停，支持逐缸四冲程、曲轴角拖动及装回试转。

手机支持单指旋转、双指缩放、可收起的底部操作面板和横屏侧边面板。发动机热点、完整运转、曲轴角拖动、四列 W16 气缸选择及拆装台均可触控操作。

此仓库只包含网站静态发布文件。网站不需要账号、数据库或服务器端程序；Three.js 与模型资源随站点提供。桌面与手机布局在浏览器模拟环境中验证，尚未覆盖全部 iOS／Android 真机。

在线体验：<https://kaichengwang6-wq.github.io/glass-car-gallery/>

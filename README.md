# 玻璃车库 · GLASS GARAGE

七辆超跑模型的桌面互动收藏柜。点击玻璃车盒抽出模型，探索车门、舱盖、灯光、展示换色和各车型专属玩法。

每辆车均提供独立发动机外观、部件热点、完整气缸运转和教学拆装台。发动机默认暂停，支持逐缸四冲程、曲轴角拖动及装回试转。

此仓库是已验收 v6 的静态发布文件。网站不需要账号、数据库或服务器端程序；Three.js 与模型资源随站点提供。桌面浏览器体验为当前验收范围。

模型属于独立构建的展示与机械教学示意，不是原厂 CAD。原厂资料、教学边界及第三方许可证见 [模型与资料说明](credits.html) 与 `vendor/three/LICENSE`。
